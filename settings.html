Email Configuration Guide
Gmail Setup Instructions:
  1. Enable 2-Step Verification on your Google account
  2. Go to App Passwords
  3. Select "Mail" as the app and "Other" as the device
  4. Generate a 16-character app password
  5. Use this password in your application configuration
Important Notes:
  • Never use your regular Gmail password
  • App passwords are more secure and can be revoked
  • Test email functionality after configuration
  • Check spam folder if emails are not received
