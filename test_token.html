Test Honeytoken Access

What this does:

This tool simulates a honeytoken access attempt to test the alert system. It sends a fake API request that will trigger an alert in the system.

Test Parameters
How It Works
  1. Generate Test Token: Creates a fake honeytoken value
  2. Send API Request: Sends request to /api/log_access
  3. Log Access: System logs the access attempt
  4. Analyze: System classifies the access (normal/suspicious/malicious)
  5. Alert: If suspicious/malicious, creates an alert
  6. Monitor: Check Alerts page to see the result
Note:

This is a simulation. In real usage, honeytokens would be placed in your actual systems (code repositories, databases, config files) and accessed by attackers or automated tools.

API Example

This is the API call that will be made:

POST /api/log_access
Content-Type: application/json

{
    "token_value": "TEST_TOKEN_123456",
    "action_type": "TEST",
    "payload": {
        "test": true,
        "user_agent": "Test Browser",
        "source": "test_page"
    }
}

To integrate with your applications, send similar POST requests when honeytokens are accessed.
